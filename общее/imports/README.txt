Положи сюда CSV-выгрузки из каталога посевов.

Telemetr: раздел «Рекламные посты» / Ads Posts → фильтр «vpn» + объект «бот» → экспорт CSV.
Имя файла лучше начать с telemetr_*.csv

TGStat: поиск публикаций / упоминаний vpn за последние дни → экспорт.
Имя файла лучше начать с tgstat_*.csv

Скрипт сам вытащит @логины, название и аудиторию, если колонки узнаваемые.
