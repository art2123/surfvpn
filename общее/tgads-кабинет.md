- Пустой таргет → *Will not be shown anywhere.*

## Деньги, частота, статус

| Поле в кабинете | Зачем | Дефолт на старте |
|---|---|---|
| **CPM in Euro** | Потолок ставки за 1000 показов (аукцион second-price) | см. таблицу ниже |
| **Initial budget in Euro** | Сколько кладём на объявление | **€5** (дефолт теста) |
| **Daily budget in Euro** | Потолок в день, **Set daily limit** | **= Initial budget** (€5) |
| **Daily views limit per user** | Показов одному человеку за сутки | **1** |
| **Initial status** | После модерации | **On Hold**, Active — руками когда креатив и CPM проверены |
| **Start date / End date** | Вкл / пауза по времени | выкл |
| **Ad Schedule** | Почасовка | выкл |

CPM и бюджеты **не** входят в `?start`. CPM и бюджет после создания обычно можно править; таргет — нет.

### Какой CPM ставить

Текущий кабинет **TLGM / getSurfVPN** — EUR (`_eur` в коде связки). Ставки TON и евро не сравнивать как одно число.

Ориентиры RU VPN (EUR-кабинет, 2026): ниша ~€1.5–2.5, гео CIS дешевле западного. У Blanc на похожих каналах фактический CPM часто выходил примерно €2–6 при живой отдаче.

Стартовые потолки (пока нет своей статистики):

| Target | Стартовый CPM | Почему |
|---|---|---|
| Channels, один канал | **€1.50** | узкий слот, часто дешевле широкого Users |
| Channels, список `c01`… | **€2.00** | несколько аукционов сразу |
| Bots | **€2.00** | |
| Search | **€2.00** | |
| Users | **€2.50** | широкий аукцион, легче переплатить |

**CPM — потолок** (second-price): платим примерно цену второго места, не всегда свой бид. Высокий потолок = чаще выигрываем и *можем* платить дороже при жёсткой конкуренции. Быстрый слив daily чаще = **переплата потолка**, не обязательно кликбот.

### Зачем бампать CPM

Бамп нужен **только чтобы выиграть аукцион и получить показы** (недолив). Не для «улучшения качества» и не потому что прошло N часов само по себе.

- Есть показы и воронка живая → **не бампать**, смотреть покупки/триалы.
- Показов почти нет при живом бюджете → бамп по сетке ниже (до потолка ~€7–9), иначе связка бесполезна.
- Уже €8–9+ и всё ещё тишина ≥1 день → **Hold**, не дожимать.

Цель: **минимальный CPM**, при котором есть показы и нормальная воронка. Ориентир ниши ~€2–6 факт.

**Evergreen на свой бот (`getsurfvpnbo`):** KPI и ставка — **решим отдельно** (сейчас в кабинете CPM €10). Пока не трогать лестницей недолива без команды.

### Приоритет воронки (главное)

Сравнение связок и решение «долить / Hold / забыть»:

1. **Покупки** — главный приоритет.
2. Если покупок ещё нет → **триалы** (это живые люди, не склик).
3. Дешёвый клик **сам по себе** не победа.

Пример: 100 кликов по €0.30 и **3 триала** vs 100 кликов по €0.70 и **30 триалов** → важнее **вторая**, хотя клик дороже.

Старты без триалов (velvet-тип vs technoinside) — не масштабировать бюджет, пока trial/start не подтянется.

**Stopped из‑за `daily < daily_spent`:** если связка по воронке ок → **поднять daily (и budget при необходимости)** и вернуть Active. Не бросать победителя из‑за потолка дня.

### Сетка недолива (возраст Europe/Berlin)

Возраст = календарные сутки+ с `дата` в **Связках** (или с первого Active, если дата пустая), TZ **Europe/Berlin**. Бампить только **Active**. In Review / On Hold — не бампать.

| Views | Возраст | Действие |
|---|---|---|
| **0–10** | &lt; 1 суток | ждать |
| **0–10** | ≥ 1 суток | CPM **+€1** (цель довести открут, потолок ориентир **€7–9**). Если уже **€8–9+** → **On Hold** |
| **11–49** (типично ~30) | ≥ 1 суток | кандидат: **+€0.50** постепенно к €7–9 **или** Hold, если ставка уже высокая / смысла нет |
| **50–99** | ≥ 1 суток, недолив | CPM **+€0.50** |
| **100+** | недолив при живом daily | CPM **+€0.25** |
| любые | CPM **€8–9+** и мало/0 смысла в откруте **≥ 1 суток** | **On Hold**, не +ещё €1 |

После бампа — `cpm` + `заметка` в Связках. Ревизию сетки делаем **вручную 2–3 раза в день** (отдельного крона нет).

Остальные сигналы:

| Сигнал | Действие |
|---|---|
| Воронка ок (триалы/покупки), daily доживает | **не трогать** CPM; бюджет при покупках/уверенных триалах |
| ≥50% daily за &lt;6ч **или** ≥80% daily за &lt;3ч | CPM **−~20%**; `заметка`: `переплата CPM` / `быстрый слив` |
| Stopped, `daily < daily_spent`, связка ок | поднять daily/budget → Active |
| Много кликов дорого, стартов/триалов мало, CTR низкий | **`дорогой клик`** |
| CTR ≥10% после ~1k | **`скрутка кликов`** |
| Target Bots, MAU большой, **views ≈ 0** сутки+ (боты «не смотрят») | **`накрученный бот`**, On Hold; в Слаги. MAU перед Create проверяем, но **высокий MAU не гарантия** |

Не смешивать: **недолив** → сетка; **переплата** → вниз; **скрутка / дорогой клик / накрученный бот** → Hold; **воронка** → покупки > триалы > дешёвый клик.

Прочее:

1. Recommended range — старт у **нижней** границы.
2. Channels CPM ≠ Users CPM.
3. Масштаб бюджета > теста — когда на €5 уже есть триалы (лучше покупки), не «чтобы набрать показы».
4. Темп: [tgads-snapshots/README.md](tgads-snapshots/README.md), `tgads_pace_check.py`.

€5 при низком CPM даёт больше тестовых показов, чем высокий потолок на том же кошельке.

### Алгоритм любой правки в кабинете (обязательно)

Манипуляция **не завершена**, пока не обновлена вкладка **Связки** и не **проверен** кабинет после mutate. Порядок:

1. Сделать правку в кабинете (UI или `Aj.apiRequest` — см. [tgads-api.md](tgads-api.md)).
2. **Синхрон кабинета:** перезагрузить список (`/account` или свежий `adsList`) и убедиться, что `status` / `cpm` / `budget` / `daily_budget` совпали с ожидаемым. `adsList` после mutate часто **stale** — без reload не считать успех.
3. **В том же заходе** обновить колонки в **Связках** по `ad_id` / `start_param`:

| Что меняли в кабинете | Колонка в Связках |
|---|---|
| Active / On Hold / Stopped / дорогой клик / скрутка кликов / накрученный бот | `статус` |
| CPM | **`cpm`** |
| Budget (остаток/лимит объявления) | `budget` |
| Daily budget | `daily_budget` |
| URL / title | `promote_url` / сверка `start_param` |

4. В `заметка` коротко факт (например `CPM→4 (дата, views=3)`).
5. Только после шагов 2–4 отвечать, что правка сделана.

Нельзя: поменять CPM/статус в кабинете и «потом допишу в таблицу».

**Снятие бюджета после On Hold:** не блокируем заход ожиданием ~10 мин. Остатки чистим **отдельным запросом** пачкой (`decrAdBudget`→0), когда удобно. **`deleteAd` пока не делаем.**

### Статусы качества площадки

| Статус | Сигнал | Действие |
|---|---|---|
| **дорогой клик** | CPC высокий, CTR низкий/норм, стартов/триалов мало при views | On Hold; Слаги |
| **скрутка кликов** | CTR ≥10% после ~1k; клики есть, стартов почти нет | On Hold в тот же день; `scope=s` → Слаги; список `l` → пауза всего набора |
| **накрученный бот** | Target Bots: MAU может быть огромный, а **views ≈ 0** сутки+ (аудитория бота не видит рекламу / накрутка MAU) | On Hold; Слаги «накрученный бот»; больше не целить. Перед Create Bots — смотреть MAU, но **не верить MAU вслепую** |

Признаки **мёртвых** каналов/ботов (нет MAU, крошечный канал, мёртвая лента, накрутка) — [tgads-мёртвые-площадки.md](tgads-мёртвые-площадки.md). Не путать с недоливом на крупной живой площадке.

Нормальный CTR: ~1–4%. 6–9% — жёлтая зона (конверсия в старт/триал, не масштаб).

Search: метки нет — **не анализируем** воронку; крутим. Стоп только по кабинетным аномалиям.

### Модерация — блэклист формулировок

Собираем по факту Decline. Пока жёстко:

- **YouTube / Ютуб** в тексте — **не берём** (уже ловили Prohibited / удаляли).

Дальше дописывать сюда по каждому Decline (`заметка` + эта секция).

Product claims можно чуть усиливать; кабинет за лёгкое приукрашивание не банят. Не тащить саппорт-промокоды / MTProto / разовые ключи.

### Тексты t01 / t04 — как сравнивать (предложение)

Search исключаем. По tagged связкам (Channels/Bots/Users):

1. **Парный срез:** один `slug`, оба текста Active ≥N дней → winner по **покупки → триалы → старты** (дешёвый клик не победа), при ≥~20 стартов на сторону или явный разрыв.
2. **Агрегат:** trial/start и buy/start по `tx`; пока разрыв мягкий — **оба крутим**.
3. **Погашение:** слабый текст гасим точечно на проигравших slug’ах, не глобально за день.
4. Новый текст (`t05`…) — 5–10 контрольных площадок paired с лидером.

Пока t04 чуть впереди по trial/start, но не везде — **не гасим t01 глобально**.

## Target

Четыре вкладки — это четыре разных продукта. В форме дефолт: **Channels**. Код в `start_param`: Search `s`, Bots `b`, Users `u`, Channels `c`.

**Сейчас тест каналов/ботов — только один объект на ad (`scope=s`).** Не класть 10 ботов в один список: один склик/накрут убивает статистику всех, а виновника по метке не видно. Подробнее: [tgads-нейминг.md](tgads-нейминг.md) § «Поканальное / поботовое тестирование».

### Search

- **Target search queries** — список запросов (`Add search queries`).
- В URL **нет** `?start` → аналитика по метке/`bot_start` **невозможна**. Крутим; воронку по тексту/площадке не разбираем. Стоп только по кабинетным флагам (скрутка CTR, бешеный слив).
- Ad title всё равно = код связки (для учёта в кабинете и Связках).

### Bots

- **Target specific bots** — `t.me bot URL`.
- **Add similar bots** — похожие боты по выбранным.

### Users

Аудитория людей, не конкретный канал:

- **Target countries**
- **Target locations** — город, район (`Search locations by country`)
- **Target user languages**
- **Target topics** (+ *Only target users interested in all selected topics*)
- **Target channel audiences** — аудитория указанных каналов
- **Target device type:** All devices / iOS / Android / Mobile / Desktop
- **Show this ad in channels related to Politics & Incidents only**
- **Exclude topics**
- **Exclude channel audiences**
- **Do not show this ad in channels related to Politics & Incidents**

### Channels

То, что бьётся с вкладками инвентаря в таблице:

- **Target channel languages** — `Select languages (optional)`
- **Target topics** — `Select topics (optional)`
- **Target specific channels** — `t.me channel URL (optional)` + **Add similar channels**
- **Exclude topics**
- **Exclude specific channels** — `t.me channel URL to exclude`
- **Ad placement:** **Message in Channel** (дефолт) или **Banner in Video**

## Бриф одной связки

Объявление не создаём, пока нет пунктов 1–8. **Пункт 8 (админка) — до Create Ad.**

1. **Target:** Search / Bots / Users / Channels
2. **URL you want to promote** — `t.me/surfvpn?start=…` или `t.me/getSurfVpnBot?start=…` (один бот); Search без метки
3. **Ad title** (= код связки), **Ad text** (`t01`…), **Ad photo or video** (`i01`…), **Ad Button**
4. **CPM in Euro** по таблице + **Initial budget €5** + **Daily budget €5** (evergreen свой бот — отдельно)
5. Таргет: каналы / боты / запросы; slug из **Слаги** или номер списка
6. **Initial status:** On Hold
7. **Daily views limit per user:** 1
8. Код связки заведён в админке (промокоды / кампании), иначе стата не пишется
9. Перед Create — нет дубля **Ad title** / `start_param` в кабинете и Связках
10. После Create Ad — строка во вкладку **Связки**. Без строки связка не считается залитой.
11. Любое изменение в кабинете — **reload/verify** + те же цифры в **Связки** (см. алгоритм). Без синхрона не завершено.
