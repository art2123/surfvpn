# Мёртвые каналы / боты — признаки (TG Ads)

Чеклист перед Create Ad и при ревизии **0 views** ≥1 суток. Не путать с **недоливом** на живой большой площадке (высокий CPM / аукцион): у `@shukavpn` / `@quattrovpn_news` / `@sotavpn` 0 views при €5 — сначала сетка CPM, не «мёртвый».

## Жёсткие признаки (не целить / Hold + снять budget)

| Признак | Где смотреть | Порог / сигнал |
|---|---|---|
| **Нет MAU у бота** | t.me карточка бота: нет строки *monthly active users* | MAU не показывается ≈ аудитория **&lt; ~1 000** → **накрученный/пустой бот**, не лить |
| **Низкий MAU** | t.me / инвентарь «Месячная аудитория» | ориентир **&lt; ~5 000** для теста €5 (ниже — почти нет кому показывать) |
| **Крошечный канал** | подписчики | **&lt; ~5 000** (часто &lt;2 000) — нет смысла в Ads; пример `@surfnetnews` ~1.3k |
| **Мёртвая лента** | последний пост | нет постов **≥ ~6–12 мес** или последний пост в прошлом календарном году при текущем сезоне → канал «архив» |
| **Пустой/фейковый ER** | Telemetr / глазами | огромные подп. + **мало реакций/просмотров** на пост, «бесплатно» в описании VPN-канала → подозрение на накрутку (см. `@barryvpn`) |
| **CLONE / угнанный логин** | инвентарь, Telemetr ⛔ | клон чужого бренда / hijack — не брать |
| **Раздачи конфигов / MTProto / ключи** | описание, лента | вне продукта; блэклист инвентаря |

## Мягкие (жёлтая зона)

| Признак | Действие |
|---|---|
| MAU 5–20k, 0 views ≥1д при CPM уже €5+ | Hold или CPM-сетка; не масштабировать |
| Канал 5–20k, редкие посты, ER низкий | одна связка max; быстрый Stopped если 0 views |
| Бот с MAU, но views≈0 сутки+ при живом бюджете | статус **`накрученный бот`** (кабинет + Слаги) |

## Что *не* является «мёртвым»

- 0 views на **крупном** VPN-media (100k+) в первые сутки / при низком CPM → **недолив**, бамп по сетке `tgads-кабинет.md`
- Stopped после слива daily на живой воронке (триалы/покупки) → долить, не списывать как мёртвый
