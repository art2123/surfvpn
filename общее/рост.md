# Рост на ближайшие 8 недель

Два направления. Пока нет склейки клика с `telegram_id`, CAC и победителя оффера считать нельзя.

## Неделя 0 (до бюджета)

События + `yclid` в start-параметре бота + person merge + три цели Метрики + разметка A/B. Иначе недели 1–8 неизмеримы.

## A — PPC

Директ РФ + TG Ads РФ. Отдельные кампании: **бренд** и **generic VPN**. Конкуренты — только если нужно, тоже отдельно.

Стоп: CAC first-pay выше ~400–500 ₽ две недели подряд на generic — резать, не «дообучать» бюджетом.  
Стоп по качеству: activation 24ч у платного << органики — чинить онбординг, не масштабировать.

### Конверсии обратно в Директ

События бота на лендинге JS-целями не поймать. Нужны offline-конверсии: `yclid` на сайте → `t.me/bot?start=yd_…` → `telegram_id` ↔ `yclid` → upload в Метрику.

Слать три цели, стратегию ставить **только на первую оплату с суммой**:

| Цель | Зачем |
|---|---|
| `bot_start` | воронка и аудитории, не bidding |
| `activation_connect` | качество, тот же first connect после доступа |
| `first_payment` | автостратегия |

Продления с рассылок на тот же `yclid` не вешать.  
A/B не размазывать на 4 кампании Директа: один URL, эксперимент в PostHog.  
Окно атрибуции лучше ~21 день: на 3-дневном триале оплата часто на день 3–5.  
Яндексу обычно нужно ~10+ целевых конверсий в неделю на кампанию. Generic на старте — ручное CPC, не оптимизация за `/start`.  
TG Ads — свой click/start-параметр, не смешивать с `yclid`. Схема меток: [tgads-нейминг.md](tgads-нейминг.md). Поля кабинета: [tgads-кабинет.md](tgads-кабинет.md).

## B — рассылки

Не контент и не вся база. Сегменты:

- expiry −48ч / −24ч / 0 / +24ч
- trial day 0 и day 2 без коннекта
- paid без коннекта 3 дня
- last seen 14–30 дней

Не трогать: last seen >90д, blocked, никогда не коннектились и не платили.

KPI: renewal vs holdout, revenue / 1000 sent, block/unsubscribe. Не охват.

## A/B прайсинга

Только новый трафик лендинга, не старая база 297 ₽.  
Победитель: валовая прибыль на 1000 кликов за 30 дней + доля дошедших до connect.

## Гипотезы (не факты)

1. Платить за новых можно, если CAC < ~400–500 ₽ и repeat платного канала хотя бы ~40%+.
2. Месяц ~470 ₽ может быть прибыльнее 297 ₽ (архив это уже доказал по выручке).
3. Триал может проиграть no-trial, если за 3 дня нет коннекта.
4. 664k без подписки — в основном не сегмент рассылки.
5. Короткие 7д на PPC купят низкий LTV.
6. Пик марта / летняя яма — сначала выяснить канал, не списывать на сезон.
7. Пока события ≠ люди и Unknown-тарифы не размечены, «конверсия выросла» будет ложью.
