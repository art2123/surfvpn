# Именование связок TG Ads

Схема из чата [TG Ads naming system](16b32c43-09fa-47a3-8ac4-499985cce773). Поля кабинета — [tgads-кабинет.md](tgads-кабинет.md).

Связка = **Target** + креатив + кого таргетим. Одна связка = одно объявление = один **Ad title**.  
**Ad title** всегда = код связки. Тот же код идёт в `?start`, **кроме Search** — в поисковой выдаче метку вставить нельзя.

Бот-получатель: [@surfvpn](https://t.me/surfvpn) = [@getSurfVpnBot](https://t.me/getSurfVpnBot) (один бот, разные алиасы). В `promote_url` допустим любой.

```text
https://t.me/surfvpn?start=tga_c_i01_t01_s_technoinside_eur
```

или `https://t.me/getSurfVpnBot?start=…` — то же самое.

Search: **Ad title** = `tga_s_i01_t01_l_q01_eur`, **URL** без `?start`. Статистика Search — только кабинет по Ad title; `bot_start` по метке нет — воронку Search не анализируем.

Telegram: `start` ≤ **64**, только `A–Z a–z 0–9 _ -`. Не смешивать с Директом (`yd_` / `yclid`).

---

## Схема

```text
tga_{pl}_{cr}_{tx}_{scope}_{slug}_{cab}
```

| Слот | Коды | Смысл | Поле кабинета |
|---|---|---|---|
| `tga` | всегда | Telegram Ads | префикс |
| `pl` | `s` / `b` / `u` / `c` | Search / Bots / Users / Channels | вкладка **Target** |
| `cr` | `i01`… / `v01`… / `x` | сквозной номер картинки / видео / без медиа | **Ad photo or video** |
| `tx` | `t01`… | сквозной номер текста | **Ad text** |
| `scope` | `s` / `t` / `l` | как набран таргет: один канал/бот / топик кабинета / свой набор | см. ниже |
| `slug` | `a-z0-9`, ≤12 | канал, бот, топик или id списка | кого целили |
| `cab` | `eur` / `ton` | в каком кабинете крутится | EUR (€) или TON |

Текущий кабинет **TLGM / getSurfVPN // CR_Telegram Ads (2)** — **`eur`**. Одна и та же связка в двух кабинетах = два объявления и два кода (`…_eur` и `…_ton`), иначе расход и старты смешаются.

Номера **двузначные** (`i01`, `b01`), чтобы сортировка и статистика не ломались на `i2` vs `i10`.

### Scope — как набран таргет

Вкладка Target (`pl`) = *где* крутим. Scope = *кого туда положили*.

| Код | По-русски | В кабинете | Slug | Статистика |
|---|---|---|---|---|
| `s` | **Один канал или один бот** | В **Target specific channels** / **Target specific bots** ровно один `t.me/…` | юзернейм из **Слаги** (`technoinside`) | ROI площадки |
| `t` | **Топик кабинета** | Только **Target topics** (Technology & Internet, Economy & Finance, …), без ручного списка URL | короткое имя топика (`finance`, `tech`) | ROI темы, не канала |
| `l` | **Свой набор** | Несколько каналов, несколько ботов или пачка search-запросов; у Users — широкая аудитория | номер набора `c01` / `b01` / `q01` или `broad` | ROI всего набора, не каждого участника |

Пример: только `@technoinsider` → `…_s_technoinside_eur`. «Каналы про финансы, какие Ads сам подберёт» → `…_t_finance_eur`. Три выбранных VPN-канала → `…_l_c01_eur`.

### Поканальное / поботовое тестирование (сейчас)

Пока фаза теста каналов и ботов — **только `scope=s`** (один `@login` на объявление).

Зачем: в списке из 10 ботов (`scope=l` / `b01`) один скликиваемый / накрученный портит метрику всего набора, а **какой именно — по `tga_…` не видно**. Мы продолжали бы крутить «хороший список», сжигая бюджет на грязном участнике.

- Channels / Bots тест → всегда отдельная связка на каждый логин (`…_s_{slug}_…`).
- Наборы `c01` / `b01` для закупки **не используем**, пока не закроем одиночный прогон и явный апрув на списки.
- Search `q01` — исключение (запросы, не площадки); воронку по Search всё равно не разбираем.
- Скрутка / дорогой клик / накрученный бот на `scope=s` → сразу Слаги, этого логина больше не целим.

## Сквозная нумерация

Номер выдаём из реестра в таблице, **следующий свободный**, никогда не переиспользуем. Перед созданием объявления смотрим вкладки, не выдумываем с потолка.

| Что | Код | Где реестр | Правило |
|---|---|---|---|
| Картинка | `i01`, `i02`… | **Креативы** | Один файл = один номер навсегда, на всех Target |
| Видео | `v01`, `v02`… | **Креативы** | то же |
| Текст | `t01`, `t02`… | **Креативы** | Один текст = один номер на всех Target. Эмодзи — колонка в реестре, не слот метки |
| Набор ботов | `b01`, `b02`… | **Списки** | `scope=l`, `pl=b` |
| Набор каналов | `c01`, `c02`… | **Списки** | `scope=l`, `pl=c` |
| Набор запросов | `q01`, `q02`… | **Списки** | Search, `scope=l` |

`i01` + `t01` в Channels и в Bots — **тот же** креатив. Иначе в PostHog нельзя сложить картинку по всем плейсментам.

Эмодзи в `?start` не кодируем. Текст с эмодзи и без — разные номера (`t01` / `t02`), признак смотрим во вкладке **Креативы** (колонка **эмодзи**: да/нет). Сравнение «с эмодзи vs без» в статистике: `_t01_` vs `_t02_`, затем джойн к реестру. Не правило «нечётный = эмодзи»: `t03` снова может быть с эмодзи, если это другой оффер.

## Сквозное именование каналов и ботов

Один `@login` → один slug навсегда. Иначе статистика по площадке разъедется (`technoinside` vs `techins`).

1. Взять юзернейм без `@`, нижний регистр, выкинуть `_` и `-`.
2. Если ≤12 `a-z0-9` — **целиком** (`blancvpn`, `fckrknbot`).
3. Если длиннее — первые 12 (`technoinsider` → `technoinside`). Столкновение — дописать цифру, не отрезать вслепую до 7 букв.
4. Записать во вкладку **Слаги** *до* первого объявления.

| scope | slug | Пример Ad title / `?start` |
|---|---|---|
| один канал | slug из **Слаги** | `tga_c_i01_t01_s_technoinside_eur` |
| один бот | slug из **Слаги** | `tga_b_i01_t01_s_fckrknbot_eur` |
| набор каналов | `c01`… | `tga_c_i01_t01_l_c01_eur` |
| набор ботов | `b01`… | `tga_b_i01_t01_l_b01_eur` |
| топик Ads | короткое имя топика | `tga_c_i01_t01_t_finance_eur` |
| Search-кластер | `q01`… | Ad title `tga_s_i01_t01_l_q01_eur`, без `?start` |

Три канала в одном объявлении → статистика только на список `c01`, не на каждый канал. Нужен ROI по `@technoinsider` отдельно — отдельная связка `scope=s`.

**Списки:** `slug | тип | логин | ссылка | название | заметка`. `тип`: `bots` / `channels` / `queries`.

### Архив залитых связок

Источник правды — вкладка **Связки**, не локальный CSV и не чат. Текст и картинка живут в **Креативах**, состав набора — в **Списках**; в архиве только код (`t01`, `c01`) плюс то, что уникально для объявления в кабинете.

Колонки:

`start_param` | `ad_id` | `ads_url` | `cab` | `pl` | `cr` | `tx` | `scope` | `slug` | `дата` | `статус` | `cpm` | `budget` | `daily_budget` | `promote_url` | `промокод в админке` | `заметка`

`промокод в админке`: `нет` / `добавлен`. После вставки кодов в Marketing Panel — ставить `добавлен`.

`ads_url` = `https://ads.telegram.org/account/ad/{ad_id}`.  
`статус`: On Hold / Active / Stopped / **дорогой клик** / **скрутка кликов** / **накрученный бот** (устаревшее «склик» = скрутка кликов).

Правила:

1. Строка пишется **в тот же заход**, что и Create Ad. Объявление без строки в **Связках** считаем не залитым.
2. Строку в таблице не удаляем: пауза / дорогой клик / скрутка / накрученный бот — смена `статус`. Из кабинета объявления **пока не удаляем**; budget→0 — отдельной пачкой по запросу.
3. Следующий `start_param` / **Ad title** сверяем с архивом **и** с кабинетом: **дубликат кода нельзя**.
4. Скрутка / дорогой клик / накрученный бот → статус + пометка в **Слаги** при `scope=s`.
5. В админку кампания попадает **до** Create Ad, не после.
6. **Любая** манипуляция в кабинете в **том же заходе**: reload/verify + запись в **Связки**. Смена ставки → **`cpm`**. Чеклист: [tgads-кабинет.md](tgads-кабинет.md).

### Админка: промокоды / кампании (обязательно до заливки)

Без строки в сервисе промокодов Marketing Panel стата по связке не считается. Create Ad в Telegram Ads **нельзя**, пока код не заведён в админке.

Куда: админка → промокоды / кампании. Коды с префиксом `tga` бот понимает как ссылку размещения: `t.me/surfvpn?start=КОД`.

Два способа:

1. **Вручную**, по одному коду на строку. Каждая строка = активная кампания с таким **названием и кодом**. Так заводим все связки, даже без скидки.
2. **CSV со скидкой:** `код;процент`  
   Имя VPN — сегмент кода **перед последним `_`**: `tga_c_x_t01_s_vpngen_eur` → `vpngen`. В боте создаётся промокод-скидка `VPNGEN50` (slug в верхнем регистре + процент) и привязывается к кампании. Уже заведённая кампания без промокода получит его и попадёт в «обновлены».

Наш `{cab}` как раз последний слот, поэтому парсер админки забирает slug: `…_s_technoinside_eur` → `technoinside`, `…_l_c01_eur` → `c01`.

Порядок: выдать `start_param` → вставить в админку → Create Ad → строка в **Связки**, колонка **промокод в админке** = `добавлен`.

Список кодов для вставки (On Hold/Active без «добавлен»):

```bash
python общее/scripts/export_tgads_admin_campaigns.py
python общее/scripts/export_tgads_admin_campaigns.py --csv 50   # если нужна скидка
python общее/scripts/export_tgads_admin_campaigns.py --all      # весь архив
```

Слепок метрик (дата/время, CTR, spend, CPM) перед Active и для сверки склика / темпа слива / переплаты CPM:

```bash
python общее/scripts/snapshot_tgads_svyazki.py
python общее/scripts/snapshot_cabinet_ads.py path/to/adslist.json
python общее/scripts/tgads_pace_check.py [--apply]
```

Каталог: [tgads-snapshots/](tgads-snapshots/). Baseline первой волны: `2026-09-17_161800_Europe-Berlin`. Ритм и флаги — [tgads-snapshots/README.md](tgads-snapshots/README.md).

## Примеры

| Связка | Ad title | `?start` |
|---|---|---|
| Channels → @technoinsider, EUR | `tga_c_i01_t01_s_technoinside_eur` | да |
| то же в TON-кабинете | `tga_c_i01_t01_s_technoinside_ton` | да |
| Channels → набор `c01`, EUR | `tga_c_i01_t01_l_c01_eur` | да |
| Bots → три бота `b01`, EUR | `tga_b_i01_t01_l_b01_eur` | да |
| Search → кластер `q01`, EUR | `tga_s_i01_t01_l_q01_eur` | **нет**, URL `t.me/surfvpn` |
| Users → широко, без медиа, EUR | `tga_u_x_t01_l_broad_eur` | да |

Фильтры: все Channels — `tga_c_`; картинка 1 — `_i01_`; @technoinsider — `_s_technoinside_`; весь евро-кабинет — `_eur`.

Не использовать черновик `bot_i1_t1_technoinsider_ch`.

## Что не класть в код связки

Оффер и A/B тарифа — PostHog. Эмодзи — колонка в **Креативах**, не суффикс метки. **CPM**, бюджеты, **Daily views**, расписание, язык, exclude, **Ad placement** — только кабинет.

## Парсинг (когда будет код бота)

```text
^tga_(s|b|u|c)_(i\d+|v\d+|x)_(t\d+)_(s|t|l)_([a-z0-9]{1,12})_(eur|ton)$
```

В `bot_start`: целиком `start_param` + `tga_placement`, `tga_creative`, `tga_text`, `tga_scope`, `tga_slug`, `tga_cabinet`.
